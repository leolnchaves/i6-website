## Cómo usar este material

El PDF reúne, en un único documento, el contenido de las páginas de
introducción, autenticación y referencia de la API. Es la versión indicada para
circular en revisiones internas y comités de arquitectura.

## Estructura del documento

| Sección | Contenido |
| --- | --- |
| 1 | Visión general de la integración |
| 2 | Autenticación y emisión de tokens |
| 3 | Referencia de endpoints |
| 4 | Buenas prácticas de implantación |

## Checklist antes de empezar

- entorno de homologación disponible
- token de acceso emitido
- contrato de datos de entrada validado con el equipo de negocio
