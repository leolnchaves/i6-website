# Busca documental na documentação

Hoje a busca do menu lateral da documentação compara o termo apenas com o título da página. Buscar "frame" não encontra nada se a palavra estiver só no corpo do texto.

## O que muda

- A busca passa a olhar dentro do conteúdo de cada página (título, descrição e texto completo), não só o nome.
- Cada resultado mostra um pequeno trecho do texto onde o termo aparece, com o termo destacado, para o leitor saber por que aquela página apareceu.
- Continua funcionando sem acentos e sem diferenciar maiúsculas ("Frame" acha "frame", "sessao" acha "sessão").
- Ordem dos resultados: primeiro páginas com o termo no título, depois na descrição, depois só no texto.
- Quando o campo está vazio, o menu volta a ser exatamente a lista de seções e páginas de hoje.
- Textos de apoio ("Buscar na documentação", "Nenhuma página encontrada") atualizados nos três idiomas para refletir busca no conteúdo.
